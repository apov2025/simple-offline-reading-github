# 两款机型的硬件对照

目标是同一个阅读器固件适配两款机型：思维重置「小纸 Pico」和 Metalio E-Ink 4 Plus。这里记两者的硬件差别和它对固件的影响。小纸 Pico 已实测；Metalio 首版已烧录，用户已确认可阅读翻页和按键分工；后续候选出现唤醒后静置黑影扩大的异常，实机测试已暂停；前光、屏幕与休眠尚未完成验收。

资料日期：2026-11-18，已复核官方提交 `2e8501095eaf1980be0d6d8b7005d0ffeae505f7`。Metalio 一栏来自官方开源固件仓库 [CloudZao/Metalio-E-INK4-Plus](https://github.com/CloudZao/Metalio-E-INK4-Plus)（MIT）的说明、`config.h` 和 `sdkconfig`，实机 USB 已识别为 S31，原 mogo 启动日志确认 16MB flash/16MB PSRAM、1216×684 屏幕、20MHz 8位总线和1200mV VCOM。原固件备份内两组屏幕引脚常量与当前官方接线一致；这不能识别 PCB 丝印版本。

## 对照表

| 项目 | 小纸 Pico | Metalio E-Ink 4 Plus | 对固件的影响 |
| --- | --- | --- | --- |
| 厂商 | 思维重置 MindReset | 官方署名是深圳云造科技（CloudZao），品牌 Metalio | 无 |
| 主控 | ESP32-S3（Xtensa 架构） | ESP32-S31（RISC-V 架构，乐鑫的新芯片） | **最大的差别**。要出两个固件包，互相不能刷；编译工具链不同 |
| 存储 / 内存 | 16 MB 闪存，8 MB 内存 | 16 MB 闪存、16 MB PSRAM（当前实机启动日志） | 机身自带内容的放法可以共用 |
| 屏幕 | 4.7 寸，684×1216，16 级灰度 | 同尺寸、同分辨率、同一系列面板 | **排版和界面可以原样共用** |
| 屏幕驱动 | 主控直接驱动，16 位数据线，电源芯片 SY7636A | 主控直接驱动，8 位数据线，电源芯片 TPS65185 | 驱动思路相同，底层要各写一套 |
| 刷新波形 | 官方校准过的波形 | 自有的实验波形（官方注明在等面板厂的正式波形） | 翻页速度和残影要分别调 |
| 屏幕电压校准 | 出厂标定，存在电源管理芯片里 | 新官方代码从 BH1098 读取持久校准，需芯片固件1.08以上；本次实机原 mogo 日志采用1200mV，试用包按此值运行 | 分开读取并应用，不改写校准记录 |
| 前光 | 没有 | 有，冷暖双色 | Metalio 要多一个亮度和色温的调节 |
| 触摸屏 | CST836U | FT6336U | 换一个触摸驱动 |
| 屏幕下方三键 | 三个独立的电容键 | 三个虚拟键，由触摸芯片上报 | 含义可以一一对上（左、中、右） |
| 其他按键 | 侧面电源键 | 侧面最下小键锁屏、中间音量加减、最上大键AI/BOOT | 音量键翻页、最上大键截图；下一版长按录音笔记 |
| TF 卡 | 有 | 有，读写更快（4 线） | 引脚和速度设置分开 |
| 电源管理 | 一颗独立的小芯片管电源键、休眠和屏幕电压 | 没有这颗芯片，用电量计、充电芯片、开关机芯片和时钟芯片组合 | **差别大**。锁屏、休眠、唤醒要为 Metalio 重做 |
| 休眠 | 软休眠，单击电源键唤醒 | 官方固件只用浅睡，累计 30 分钟自动关机 | 待机耗电要实测 |
| 时钟 | 在电源管理芯片里 | 独立时钟芯片 PCF8563 | 换一个驱动 |
| 重力感应 | SC7A20H | SC7A20H（同款） | 可以共用 |
| 声音 | 蜂鸣器 | 没有蜂鸣器；有震动马达、喇叭、麦克风 | 提示音换成震动 |
| 无线 | Wi-Fi、蓝牙 | Wi-Fi、蓝牙（可接蓝牙翻页器）；另有 4G 版 | 传书功能可以共用 |
| 官方固件 | 开源（Apache-2.0），ESP-IDF v6.1 | 开源（MIT），ESP-IDF v6.1，带完整引脚表；没有公开原理图 | 两边的驱动都有现成代码可参考 |

## 结论

- **能共用的**：书库、排版、EPUB 解析、设置面板、进度、机身自带的字体和书。屏幕尺寸和分辨率完全一样，界面一个像素都不用改。
- **要为 Metalio 另写的**：屏幕驱动的底层和电源、触摸、按键、TF 卡、电源与休眠、时钟、前光。也就是"板级"那一层。
- **要多维护的**：第二条编译线（ESP32-S31）。本机装的 ESP-IDF 里有 ESP32-S31 的支持目录，已编译并完成首次上机，仍处于硬件验收阶段。
- **可行性的旁证**：已经有第三方项目用同一份阅读器源码同时支持这两款机型（kiikoread，`boards/pico` 与 `boards/metalio47` 两套硬件后端）。它新增的原创部分是"个人学习许可"，不能直接拿来用，只能参考结构。

## 没确认的

- "无名科技"与 Metalio 的关系。官方仓库和官网的署名都是云造科技；无名科技的资料站里没有这款产品。
- Metalio 的模组型号、原理图。
- Metalio 的硬件版本。官方 config.h 含 V1.2/V1.3/V1.4 引脚差异，板级驱动注释也提 V1.5；本机厂家经用户询问表示“大概是最新 V1.5”，尚未核实 PCB 丝印；原固件配置符合 XSTL4/MODE19 接线，触摸固件日志为 LT0470GF0430M_V1.1/V04。不能把触摸固件号当面板型号。
- 两台机器实际的翻页速度和待机耗电对比。

## 容易混淆的

"Metalio E-Ink 4"（不带 Plus）是另一套硬件：3.97 寸 800×480 的屏，驱动方式完全不同。这里说的都是 Plus。

## Metalio 构建与支持边界

独立构建，不能与 Pico 固件互刷：

```sh
idf.py --preview -B build-metalio -DREADER_BOARD=metalio -DMETALIO_PIN_PROFILE=plus-xstl4-mode19 -DMETALIO_VCOM_MV=1200 build
```

`plus-xstl4-mode19` 是当前实现唯一接线配置，不是 PCB 版本选择器；其他配置会报错。1200mV 仅来自本次实机原固件日志，不应作为其他机器的通用标定值。程序不持久写入校准或 efuse。

前光、触摸、四位 SD、按键和官方 S31 休眠兼容层已接入；源码与许可见 `boards/metalio/upstream/SOURCE.json`。浅睡保留 SD 供电和文件句柄，睡前等待挂载结束；仍须实测掉卡、唤醒、电流和残影。SD 没有独立插卡检测脚，三次自动恢复失败后，可插卡并按 HOME 再试。首次安装更换机内分区和内置内容，必须先留完整原固件备份；不格式化 SD。

首版不含联网传书、USB 读卡、AI 语音、摄像头或4G。设备按用户确认配置为有双色温前光、无4G、无摄像头。

前光硬件输出遵守官方单路10% PWM上限；屏幕每次刷新收尾断电，恢复失败停止扫描。相关离线修正未构成实机通过证明。
