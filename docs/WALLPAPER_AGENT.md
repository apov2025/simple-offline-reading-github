# 小纸 Pico 壁纸制作指南 / Wallpaper Agent Info

本指南供帮助用户制作壁纸的 AI agent 与维护者使用。适用于**即将合入壁纸功能的小纸 Pico 固件**，不表示 `2026.11.19-preview.16` 已经支持。这里的文件格式与目录约定仅用于小纸 Pico（Read Pico），**不适用于无名设备**。

## 交付目标

制作可复制到 SD 卡的 `.4bpp` 壁纸，并同时交付从最终文件反解的 `.preview.png` 与 SHA256 元数据 `.json`，让用户先查看实际灰阶内容。PNG 预览用于核对内容、位置和量化；不能保证墨水屏的物理灰阶、对比度、刷新残影与电脑一致。

原图、编辑稿、预览、元数据和字体许可证保留在电脑上。设备目录只放成品 `.4bpp`。保留源图，转换过程在本地完成，不上传私人图片。制作壁纸无需刷机或改变波形、电压；如用户还要求复制到设备，按本次任务的授权范围操作，并先确认文件复制完成、安全弹出。

## 原生格式

| 项目 | 约定 |
| --- | --- |
| 宽 × 高 | 684 × 1216 像素，竖屏 |
| 文件长度 | 严格 415872 字节 |
| 文件头 | 无 |
| 像素顺序 | 从左上角开始，逐行从左到右、从上到下 |
| 每像素 | 4 bit，16 个灰阶；0 黑、15 白 |
| 每字节 | 低半字节是左像素，高半字节是右像素 |
| 方向 | 不预旋转、不镜像；以原生竖屏尺寸交付 |

例如左黑右白为 `0xF0`，左白右黑为 `0x0F`。预览将每个灰阶值映射到 `0, 17, 34, …, 255`。

## 创作新壁纸

1. 根据用户已经表达的主题、用途与画面偏好准备底图。没有明确文字需求时不擅自添加标语。优先留白、清楚轮廓和可辨识的层次，避免极细纹理、过锐化、浅灰整面底色和大面积噪点。按竖屏 684:1216 构图，尽量直接以此比例出图。
2. 如使用 AI 绘图，让 AI 只画底图，不让它生成最终中文文字。对关机图，在底部提示区留空，不把主体、签名或句子放进去。
3. 确有文字时，用真正的中文字体另行排版，例如 [思源黑体](https://github.com/adobe-fonts/source-han-sans) 或 [思源宋体](https://github.com/adobe-fonts/source-han-serif)，并核对所用版本的许可证。读取字体字符表（可用 fontTools 的 `TTFont(...).getBestCmap()`），逐字检查覆盖；缺字时换合适字体，不用相似字替代。保留字体来源、许可证及所需署名。不要把商业字体当作可随意分发的素材。
4. 用正常文字绘制工具把确认过的中文排到图上。逐字核对原文、简繁、标点与换行，再查看原尺寸和最终灰阶预览，检查空框字、糊字、细笔画断裂与边缘裁切。小字或重要字笔画至少应在预览中清楚可见。
5. 文字最好在最终 684×1216 画布上排版，重要内容距四边至少 24–32px；中文可从 32px 起试排，以最终字形清晰度为准，不把这当作保证。导出不含旋转标记的 PNG 编辑稿，再按下面流程转换。保留编辑稿与字体许可证，不把字体文件或编辑稿混入设备壁纸目录。

## 处理已有图片

使用本地 Python 3 与 Pillow。若环境缺依赖，先说明缺什么，使用用户已允许的安装方式；不要为了转换图片上传私人内容或连接外部服务。图片转换本身不需要网络。

在仓库根目录执行；先创建输出目录：

```sh
mkdir -p wallpaper-output
python3 tools/prepare_wallpaper.py artwork.png -o wallpaper-output/001.4bpp
```

成品 raw 和反解 PNG 不保留原图的 EXIF、GPS 或原文件路径。会生成：

- `001.4bpp`：设备成品。
- `001.preview.png`：**从上述成品字节反解**，并非转换前缩略图。
- `001.json`：尺寸、像素约定、转换参数、源文件与成品 SHA256。

默认先按 EXIF 信息转正，再把有效内嵌 ICC 转为 sRGB，透明部分铺白，然后用 Lanczos 等比缩放、居中留白；不裁切、不拉伸，不额外锐化。没有 ICC 时按普通 sRGB 图片处理。ICC 损坏或不兼容会明确报错；优先重新导出有效 sRGB 图片。只有确认接受色彩差异后才显式加 `--ignore-icc`，工具会在终端和元数据记录此选择。

默认使用 16 灰阶直接量化，适合文字、线稿和简洁图案。只有用户接受裁切时才选 `cover`；它会居中裁去超出部分，须检查人物、文字和主体：

```sh
python3 tools/prepare_wallpaper.py artwork.jpg -o wallpaper-output/002.4bpp --fit cover
```

照片可以另做一个 16 灰阶 Floyd–Steinberg 误差扩散版本比较渐变与颗粒；这不是固定黑白两色抖动，不应给所有图默认启用：

```sh
python3 tools/prepare_wallpaper.py photo.jpg -o wallpaper-output/003.4bpp --dither fs
```

默认拒绝覆盖任何已有成品、预览或元数据。确认要替换这些生成文件后可以加 `--force`；即便如此也不会替换输入源图。保留源图，避免反复把量化后的预览当作新源图转换。

已有 raw 文件可检查长度并反解：

```sh
python3 tools/prepare_wallpaper.py --validate wallpaper-output/001.4bpp --force
```

这里的 `--force` 只允许重写已有预览和元数据，不改 raw。检查长度与解码并不能判断一个恰好等长的文件是否为正确作品，也不能检测其图像是否颠倒、字是否写错，必须查看预览。

自测（仓库集成后）：

```sh
python3 tools/test_prepare_wallpaper.py
```

## SD 卡目录与轮换约定

以下运行行为对应即将合入该功能的版本。复制文件前先确认设备已安装支持壁纸的版本，不要把指南当作 preview.16 的现有功能说明。

| 用途 | SD 卡根目录下路径 |
| --- | --- |
| 锁屏壁纸 | `wallpapers/lock/` |
| 关机壁纸 | `wallpapers/off/` |

- 扩展名必须小写 `.4bpp`，文件名不能以点开头。文件名连同 `.4bpp` 最多 95 个 UTF-8 字节；推荐纯 ASCII `001.4bpp`、`002.4bpp`。中文通常占多个字节，不能按字符数估算。
- 每个目录最多放 64 个候选成品。目录总枚举上限为 256，别放源图、预览、JSON、字体或杂项；隐藏文件也可能占枚举名额。
- 候选按 `strcmp` 字节顺序排序后轮换，不是自然数字排序；用固定宽度的编号保持直观次序。
- 锁屏仍优先使用书籍封面；有封面时不能以“没看到壁纸”判断复制失败。
- 壁纸仅在书库、正文和睡眠设置页空闲时预读，其他页面不预读；预读未完成时回退默认图，锁屏已有书封仍优先。只有一个文件时循环使用该文件，没有可用图片时回退默认图。
- 关机图底部保留区域为 **x=272、y=1144、宽=140、高=48**，即横向 `[272,412)`、纵向 `[1144,1192)`。运行时在这里叠白底“已关机”，不要放重要元素。

最终交付前：核对 `.4bpp` 长度、SHA256、预览方向和逐字文字，确认关机保留区、目录与编号，并明确说明预览尚不能代替设备上的实际观感检查。
