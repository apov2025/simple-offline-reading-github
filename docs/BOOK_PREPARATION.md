# 自己准备 EPUB metadata 与锁屏封面

本指南适用于本项目的两款设备。工具运行在电脑上；设备端只负责读取。只处理你有权使用的 EPUB，并保留原件。

## 一次完整操作

1. 解压源码包，在源码目录打开终端。安装 Python 3.10+ 和 Pillow：`python3 -m pip install Pillow`。Windows 若使用 `py -3`，把下面的 `python3` 换成 `py -3`。
2. 新建 `originals` 文件夹，把待整理 EPUB 放进去；扫描只处理该目录直接包含的 EPUB。
3. 执行 `python3 tools/prepare_books.py scan originals -o plan.json`。
4. 用文本编辑器打开 JSON 清单，逐项核对下例中的书名、作者和年份。不要删除其余原有字段，也不要改动 `source` 指向的原文件位置。

```json
[
  {
    "file": "example.epub",
    "source": "原文件的实际绝对路径/example.epub",
    "title": "示例书名",
    "author": "示例作者",
    "year": "2020",
    "skip": false
  }
]
```

上例仅解释字段，实际使用扫描生成的清单。`year` 使用字符串；不知道作者／年份时可以留 `""`，不要编造。`confidence`／`why`／`problems` 是建议依据，低置信项不会自动阻止 `apply`。不用的条目设置 `"skip": true`。若用 AI 帮忙审阅，最终仍需自己核对，尤其是作者与译者、原作年份与电子版制作日期。

5. 用一个全新的输出目录运行 `python3 tools/prepare_books.py apply plan.json -o prepared`。不要用 `originals` 作输出目录；重复输出名会覆盖输出文件。
6. 逐行检查结果。`apply` 会报告每本书的失败或缺失封面，部分失败时仍可能返回正常退出码。成功书可在电脑阅读器里打开复核。
7. 先复制一本生成的 EPUB 到 SD 卡 `books/` 测试，再处理余下书。保留原书直到确认结果。替换同名书先备份；避免同时保留原书和整理版而出现重复条目。

## 如何确定作者与年份

- EPUB 的 `dc:title`、`dc:creator` 是书库书名和作者的主要来源。缺失或明显占位内容才回退文件名。
- 文件名建议为 `书名 - 作者 (年份).epub`。年份先读文件名，再读 EPUB 中的日期。
- `apply` 同时重写 OPF 的标题、作者、日期字段和输出文件名；仅改文件名不会覆盖仍存在的错误 metadata。
- 书内正文不会被这一步改写；复杂或损坏的 EPUB、受 DRM 保护的文件不保证可处理。
- 更名或更换文件内容可能改变阅读进度对应关系，建议先记下当前位置。

## 添加或替换封面

1. 先在 EPUB 编辑工具中把自己准备的 JPG／PNG 设成该书封面。不要只把图片扔进 ZIP；需要 EPUB 2 的 cover metadata 或 EPUB 3 的 `cover-image` 标记等正确引用。
2. 保存后重新扫描并确认清单，再运行 `apply`。工具从已标记的封面或书内可识别的封面候选中取图，等比例缩放到白底画布中，转换为 16 级灰度。
3. 输出 EPUB 内会增加或替换 `pico/cover.4bpp`。它是缓存，不是普通 PNG/JPG；不要仅改图片扩展名来伪造它。
4. 拷到设备，打开正文，空闲片刻让封面读入后再锁屏。

工具支持 Pillow 可解码的图像；建议源图使用 JPG 或 PNG。缺 Pillow 时 macOS 可尝试系统 `sips`，其他平台应安装 Pillow。SVG 封面或只链接远程图片的 EPUB 不保证转换成功；先改成实际嵌入的位图再处理。

没有封面缓存仍可阅读正文，只是锁屏使用默认画面。在书库锁屏也使用默认画面。Metalio 的状态底栏会占用封面底部一部分，重要文字尽量不要靠下边缘。

## 格式约定（供开发者使用）

| 项目 | 值 |
| --- | --- |
| ZIP 内部路径 | `pico/cover.4bpp`，相对于 EPUB 根目录 |
| 画布 | 684 × 1216，竖向 |
| 字节数 | 415872，恰好宽 × 高 ÷ 2 |
| 灰度 | 4 bpp，0 黑，15 白 |
| 像素顺序 | 逐行；每字节先低四位、后高四位 |
| ZIP 压缩 | `ZIP_STORED`，不压缩 |

两设备共用这份竖向逻辑画布，底层负责屏幕旋转。当前没有可从 SD 更换默认锁屏壁纸或关机壁纸的入口；修改默认图需要改固件资源并重新编译。

## 常见问题

- **书名依然错误**：确认卡里是新输出的 EPUB，且没有打开旧副本；先检查 OPF metadata，再看文件名。
- **锁屏还是默认图**：查看输出是否提示“书里没找到封面／封面图转不了”；确认 ZIP 内条目、长度、压缩方式正确，并在正文空闲片刻后锁屏。
- **改了封面但没变化**：修改普通封面后必须重新生成 `pico/cover.4bpp`，再用新 EPUB 替换卡内文件并重新打开。
- **卡里有书但列表没出现**：确认它直接位于 `books/`，扩展名是 `.epub`，不是加密书；重新开机／返回书库触发扫描。不要在设备使用 SD 卡时拔卡写入。
