# 阅读器固件介绍

一个为小纸 Pico 做的极简阅读器固件：开机就是书库，点开就读。它建在小纸 Pico 官方开源固件之上，硬件驱动沿用官方的，界面和阅读体验是重新做的。

此前分享版已有两机试用记录。本轮小纸候选新增长按模式切换、查词跨行调整和隐藏书库；实现已更新，完整候选编译与本轮真机交互仍待验证。下文小纸新功能不代表无名同步支持。

## Metalio E-Ink 4 Plus 试用适配

Metalio 版已完成基础阅读、锁屏唤醒和前光的实机试用。共用同一书库和阅读排版，操作区别如下：

| 按键 | Metalio 功能 |
| --- | --- |
| 正面左 | HOME，返回书库 |
| 正面中 | 字体、字号、刷新与前光设置 |
| 正面右 | 全刷 |
| 侧面最下小键 | 锁屏/唤醒 |
| 音量加/减 | 上一页/下一页 |
| 侧面最上大键 | 截图保存到卡上 `screenshots` |

无书籍封面时，默认锁屏为白底、居中的 Cloud Zao 黑白标志，不叠加锁屏文字；书籍封面仍优先。

前光提供关/低/中/高及冷/中/暖，锁屏关灯、唤醒恢复。截图保存为灰度 BMP，用递增编号避免覆盖已有文件；读不到卡或写入失败会提示。

Metalio 使用浅睡，不采用下文 Pico 的主控断电方式；待机耗电尚未测量。插卡后仍只见内置书时，按 HOME 重新触发有限次数读卡恢复。安装说明与硬件边界见 [设备对照](DEVICES.md)。下面原有按键和电源说明适用于 Pico。

## 怎么用

小纸机身自带 Pico Hei 字体和两本书：沈括《梦溪笔谈》（原文简体整理）与 H. G. Wells 的 The Time Machine（英文原版）；无名仍使用原有默认书。不插卡也能阅读。自己的书放进 TF 卡的 `books` 文件夹，想换字体就把字体放进 `fonts` 文件夹，插卡后它们会和自带的排在一起。

本版新增卡恢复处理（异常恢复尚待真机验证）：卡仍插着但暂时读不到时，停留在书库会有限重试恢复；恢复后自动重新列书。不会自动格式化卡。偶发无法唤醒的问题仍在排查。本版已修正一处浅睡漏处理按键的问题，并将卡上已选字体的恢复提前到完整书库排版前，减少字体跳变；卡未就绪时仍可能先看到内置书。

- **开始使用**：只有在一本书都找不到时（机身自带的内容丢了，又没插卡）才会出现三步引导（插卡、放字体、放书），每一步右侧写着"已就绪"或"还没有"。

- **书库**：一栏一本书，书名下面是作者和年份，不显示阅读百分比，阅读位置仍会自动保存。最近读过的排在最前面，没读过的按文件名排在后面。书名一行放不下会折行显示完整（最多三行）。一页放不下时，点左下角"上一页"、右下角"下一页"翻页（上下滑动也可以），中间是"第几页/共几页"。点书名开读。
- **小纸隐藏书库**：长按书库条目，再点“隐藏”；连续点三下书库标题，在普通和隐藏书库间切换。隐藏书库中长按条目可“取消隐藏”。文件和逐书进度保留，这不是加密，电脑仍可访问文件。隐藏书不会自动续读，也不显示书封锁屏；从隐藏书库或隐藏书锁屏后，冷启动和浅睡唤醒都回普通书库。
- **书名和作者**：以 EPUB 文件里自带的书名、作者为准，所以文件叫什么名字都行。书里没写的，才用文件名补：文件名按 `书名 - 作者 (年份).epub` 来拆，例如 `三体 - 刘慈欣 (2008).epub`。年份优先用文件名里的（书里记的日期常常是电子版的制作日期），文件名里没有才用书里的。书名或作者显示得不对，说明这本 EPUB 自带的信息有误：阅读器不负责整理书，请先用下面"准备书"里的程序处理。
- **阅读**：屏幕上只有正文和一行页脚。点右侧或向左滑是下一页，点左侧或向右滑是上一页，读到章末自动接下一章。进度自动保存。

屏幕下方的三个触摸键：

| 键 | 作用 |
| --- | --- |
| 左键 | 打开或关闭设置面板。字号、字体、刷新方式都在这一层里，点一下就生效 |
| 中键 | 返回上一级：面板开着就关面板，在读书就回书库 |
| 右键 | 短按全刷一次；读书时长按切换划线／查词，书库长按打开单词本 |

设置面板里的刷新方式有三档：

| 档位 | 特点 |
| --- | --- |
| 快速 | 默认。翻页最快，文字边缘略粗糙，每隔十几页自动全刷一次 |
| 均衡 | 文字清晰，每隔十几页自动全刷一次清除残影 |
| 清晰 | 每页都全刷，最干净，翻页时会闪一下 |

随时可以按右键手动全刷一次。

## 目录与电量

读书时从屏幕顶端向下滑，松手后调出目录（手指从屏幕顶部约一指宽内开始）。设置里不再放目录按钮。目录自动翻到当前阅读位置所在的一页，并以浅灰底标出当前章节或小节。目录按书里的章节层级排列，点章节或小节即可跳到所在页面；左右滑动切换目录页，页底只保留“返回正文”，也可按正面中键回到原阅读位置。成功跳转会保存新位置；找不到目标时提示“这一章读不出来”，保留原进度。没有可用目录的 EPUB 会显示文件中的章节列表。目录不依赖封面预处理。

小纸书库不显示电池。从书库顶部向下滑可打开设备信息，显示设备名称、固件名称/版本（preview 后的内部编号不显示）和电池图标，以及“使用说明”和小纸的 USB传输入口。说明书位于 USB传输上方，点开可直接阅读和下拉目录；保存在机身，没有 SD 卡也能打开，不加入普通书库列表。面板只占屏幕顶部，下面保留书库；向上滑、点面板外或按返回键收起。设置面板也保留电池图标；电池为较淡灰色，不显示百分比或“电量”标签；正文平时不显示，电量降到 **20% 或以下**才在页脚提醒，充到 **25% 或以上**后隐藏。提示随翻页或其他正常重绘更新，不为了电量变化反复闪屏。正文页脚显示章节名、页码和页码左侧的模式图标：笔表示划线、放大镜表示查词，不显示阅读百分比。电池旁的闪电表示正在充电；读不到可靠电量时显示问号，不会把未知值当成没电。电量是设备的估计值；低电量时请及时充电。目录、设置和设备信息使用灰阶刷新；低电量图标出现在正文时也使用灰阶刷新，以保留浅灰图标，翻页可能比纯黑白快速档稍慢。

## 离线词典（小纸候选版）

把词典包中的整个 `dict` 文件夹复制到 TF 卡根目录，词库文件是 `dict/offline.dict`，随附来源和许可证也请保留。词库独立于固件，替换词库不需要刷机；旧的 `moe-mini.dict` 不再使用。通过 USB 复制时，先在电脑弹出磁盘，再在设备上点“结束”。

小纸读书默认使用划线模式。长按正面右侧全刷键切到查词模式，页码左侧图标从笔变成放大镜；再次长按切回。切换只更新图标，不额外弹提示。离书或锁屏后恢复默认划线。

查词模式下，按住正文的字词约半秒，字词会在原位置被细框框住，同一行两侧空白处显示小黑点。保持接触，先上下挪开手指看清选框，这一步仍锁定原行；挪开后停稳一下，再上下移动可换到当前页的其他可见行，左右移动调整目标。选对后直接松手查询，不必移回框里；不越当前页，也不选释义卡挡住的文字。释义出现时，临时选框和黑点消失。

识别前大幅移动仍按原来的翻页手势处理，多指触摸或操作中断会取消查询。释义卡开着时，仍可长按卡外可见正文换词；轻点卡外只关闭卡片，不会翻页。

查一个字时，相关词探测与主词查询共用一次只读词库打开，操作结束就关闭，减少重复定位。此优化不在后台查词，不跨操作占用SD文件，词库内容不变。

需要选择多个相邻字词时，点释义卡角落的选框小图标，进入原页加框界面。正文的内容、字号、断行和位置保持不变，汉字和英文单词都可选，常见英文词不省略。右键短按仍在有效松手后全刷；长按用于切换正文模式。

点击一个框选中，再点同一个框取消。可逐个选最多四个相邻汉字或英文单词，混合选择也按四项计算；若暂时选了不相邻的字词，需要调整为连续选择后确认。常见英文词同样计入四词上限。每次只在当前页选择，不支持翻页接着选。英文断词的各片段属于同一个词；恰好跨页时仅从已加载的本章原文恢复完整词，不跨章节查询。真正的连字符复合词也算一项，可以查整体及各组成部分。

确认后所有框立即消失，在原阅读页上显示释义卡。点卡片外任意位置仅关闭卡片，不会顺带翻页；按正面中键也可关闭。卡片内“重选”重新打开加框界面并清空选择，阅读位置始终保持不变。

选中一个或两个汉字查询时，还会在当前页连续汉字内匹配包含选区的词语或四字成语，最多四字、最长优先。若词库收录，完整词与所选字的释义直接显示在同一张卡上，不设额外入口；不跨标点或空白扩展。

整组查不到时，改为逐字或逐词查阅；这仅表示词库未收录，不能据此断言它不成词。卡片将字词、括号内拼音和少量简体短释义紧凑排在同一段，完整词语另起一段，以一屏容纳为目标；原字和完整词各选一至两条短释义，过长处以省略号标记。它是释义摘录，不是全部义项，不默认展开多页；不显示词性、例句和近义提示；成语省去拼音，单字和普通词组保留读音。中文不显示部首、笔画或注音符号。多音词仅在来源明确对应时逐义显示读音，否则保留已收录的读音供参考。当前字体缺少音标字形时省略该行。点卡片外或按正面中键回到原页，不改变阅读进度。

全部离线，不依据上下文自动判音或判义。扩充词库保留原维基词典词语与英文条目，并优先使用 [HanziDict](https://github.com/sinobaba/hanzidict) 中标为原创、MIT 许可的中文单字释义。按其对应《通用规范汉字表》检查，8,105 字均有条目；这不代表全部义项完整，也不保证所用字体能显示所有字形。保留不同读音各自的义项，排除源数据误把汉字引用写为拼音的读音组。来源、筛选说明和许可随词库提供，分享时请一起保留。此前中文扩充、连续查词与单词本已通过一次实机验收；英文扩充和直接翻阅也已实测可用；本轮模式切换、避让后换行及隐藏书库仍待新版真机验证。

英文扩充包采用 [ECDICT](https://github.com/skywind3000/ECDICT) 的固定 CSV 快照，补充简体中文释义，并根据已核对的词形关系处理复数、过去式和分词。所有格在精确查询未收录时再查询原词，常见缩写保留本义。派生词保留独立解释；兼有独立含义的词形可同时显示原词简义。只提供已收录释义，不自动结合上下文判断。随包保留上游许可证、来源及转换说明。

### 单词本彩蛋

在书库长按正面右侧全刷键，打开单词本；书库不显示入口按钮，短按该键仍全刷。主动查过的词会保存在 SD 卡 `notes/vocabulary.jsonl`，重复的相同查询合并、累计次数并移到最前，保留最近查询时的书名。未收录的词也记录；自动补充的相关词不额外记一条。单词本列表用稍大的字直接显示字词和短释义，通过翻页浏览；点击文字不打开卡片。每行右侧的小箭头可以打开详情，用更大的字查看释义、最近书名和查询次数；返回后仍在原列表页。浏览不增加查询次数，按正面中键回书库。释义从当前词库读取，更新词库后可补齐过去未收录的记录。

记录只保存在本地，无可靠时钟也不编造时间；可以用电脑备份或读取 JSONL 文档。SD 不可用或写入失败时仍可查词，卡片显示“未保存”。完整记录行损坏时可继续查看其他有效记录，但需要先修复文件才能继续保存；截断尾行可自动恢复。文件增大后保存需更长时间。不要在共享固件包中夹带个人单词本。

## 可选字体

本轮建议试用 [霞鹜文楷 GB](https://github.com/lxgw/LxgwWenkaiGB) 的 **v1.530 Regular TTF**。字体采用 SIL Open Font License 1.1，可免费使用和再分发，分享字体时保留其许可证。它偏楷体风格，在小字号下仍有较清楚的笔画；是否喜欢可先与内置黑体对照。

原版文件 `LXGWWenKaiGB-Regular.ttf` 约 26 MB，放在 TF 卡根目录的 `fonts` 文件夹，插回设备后从字体设置中选择。不要放进 `books`，也不用重新刷机。保留当前内置字体和默认选择不变。此版本覆盖全部基本汉字区与扩展 A，并含部分扩展 B，不能保证每个生僻字都有；已用固件渲染器检查全部 46,926 个编码字符，实际墨水屏清晰度仍需试用。

## 电源键

机身右侧的电源键：

| 操作 | 结果 |
| --- | --- |
| 单击 | 锁屏：屏幕换成锁屏图，设备进入休眠，几乎不耗电。阅读进度已自动保存 |
| 休眠时再单击 | 唤醒。普通图书可恢复原位置；隐藏图书或隐藏书库回普通书库，长按模式恢复划线 |
| 两分钟不操作 | 和单击一样，自动锁屏休眠 |

休眠时主控是断电的，所以唤醒其实是重新开机再把书打开，要等几秒，不是瞬间。

## TF 卡上的文件夹

| 文件夹 | 放什么 | 固件怎么用 |
| --- | --- | --- |
| `books` | EPUB 书 | 开机列进书库，只读不改 |
| `fonts` | TTF 字体 | 出现在设置面板里，排在"内置"后面，连内置在内最多显示 6 个 |

这两个文件夹缺了的话，开机会自动建好。卡上只放你的内容，阅读进度和设置存在机身里。

目前只支持 EPUB。

## 准备书

下载来的电子书常常书名作者填错、带着下载站的标记，有的打包方式也不规范。整理这些是电脑上的事，阅读器只读整理好的书：

```bash
python3 tools/prepare_books.py scan 放原书的文件夹 -o plan.json
```

程序会看每本书里自带的信息、文件名和书的头几页，提出书名、作者、年份，写成一份清单 `plan.json`；拿不准的标"请确认"并写明原因。清单可以交给 AI（或自己）过目、改正，然后：

```bash
python3 tools/prepare_books.py apply plan.json -o 输出文件夹
```

输出的书：书名、作者、年份已经写进书里，文件名统一成 `书名 - 作者 (年份).epub`，并重新打包。原书不会被改动。把输出文件夹里的书拷进 TF 卡的 `books` 文件夹即可。

- 它会去掉书名后面的丛书名、宣传语、版本说明，去掉作者前面的国别和"著""译"，把"姓, 名"倒回"名 姓"，不把编者、译者、绘者当作者。
- 哪段是书名、哪段是作者靠"像不像人名""在书里对不对得上"来判断，不按固定格式硬拆。
- 它会把封面提前缩成屏幕大小的灰度图放进书里：读普通图书时锁屏可以使用它，隐藏图书不显示书封。小纸没有可用书封时，优先使用已经加载的文件夹壁纸，否则显示内置锁屏图。
- 它目前不改正文，也不会自己调用 AI；AI 复核是把清单交给 Claude Code 或 Codex 这样的助手来做。

## 机身自带的内容

| 内容 | 说明 |
| --- | --- |
| 字体"内置" | 一个黑体，约 6.9 MB，收了 GBK 的全部汉字（约 2.1 万个，简体、繁体和人名地名里的生僻字基本都有）、中英文标点、英文和西欧字母。是默认字体 |
| 小纸：《梦溪笔谈》、The Time Machine | 分别为简体中文、英文原版；保留自然段、章节目录及来源说明 |
| 无名：《红楼梦》《西游记》 | 保留原有简体 EPUB |

卡上字体在菜单里按文件名显示（省略 `.ttf` 后缀），支持中文文件名；名称太长时会缩短显示。

默认用内置字体。在设置面板里选了卡上的字体之后以你选的为准；卡拔掉时自动退回内置字体，机身里的书可以接着读，卡插回来再换回你选的字体。

这些内容放在机身的存储区里，重新完整烧写固件时会恢复成出厂的样子。

## 中文排版

正文按 W3C《中文排版需求》（clreq，<https://www.w3.org/TR/clreq/>）排版。没有面面俱到，只做了其中最简单、对观感影响最大的几条：

| 规则 | 做了什么 | 为什么要紧 |
| --- | --- | --- |
| 行首禁则 | 句号、逗号、顿号、分号、冒号、问号、叹号，以及右括号、右引号、右书名号，不会出现在一行的开头 | 一行以逗号开头是中文版面里最扎眼的毛病 |
| 行尾禁则 | 左括号、左引号、左书名号不会留在一行的末尾 | 引号和它引的内容被拆到两行，读起来会断 |
| 标点挤压 | 两个标点挨在一起时（如 `：“`、`》，`、`。”`），挤掉中间多余的半个字空白；句读和右括号落在行尾、左括号落在行首时，也让出靠边的那半个字 | 全角标点自带半个字的空白，连在一起时空得很明显，行首行尾也会显得没对齐 |
| 段落顶格 | 默认不缩进，段与段之间留一点间距来分段；书里自带的全角空格缩进会被去掉，所以每本书的段落都从左边缘开始。以左引号、左括号开头的行，引号左边的空白也让出去，墨迹和左边缘对齐 | 版面干净，左边缘是一条直线 |
| 两端对齐 | 折行的每一行都把余下的空白匀到字与字之间，右边缘对齐；段落最后一行不拉伸 | 避免右边参差不齐，尤其是因为禁则而提前折行的那些行 |
| 不拆开的内容 | 省略号（……）、破折号（——）不拆成两行；数字不从中间断开 | 拆开了难读 |

标题不拉伸。段首缩进两字的排法引擎里保留着，但默认关闭。当一行空白太多（比如后面跟着一个放不下的长网址）时不硬拉字距，宁可右边留空。

"半个字""两个字"都按字体里一个汉字的实际宽度算。

clreq 里这一版没有做的：

- 标点悬挂（让行尾标点挂到版心之外）。
- 中文与英文、数字之间的自动间隙。
- 用"挤进"来消化禁则：现在遇到禁则是把前一个字连同标点一起挪到下一行（追出），有些行的字距会因此略松。
- 孤行、寡行控制，标题不落在页末。
- 竖排、注音、着重号等。

## 英文排版

英文没有一份像 clreq 那样由 W3C 出的统一规范，通行的依据有三样：TeX 的断词规则（Liang 算法，浏览器和多数电子书阅读器用的都是它）、Bringhurst《The Elements of Typographic Style》里关于词距和对齐的准则、W3C 的 CSS 文本规范里对断行和对齐的规定。同样只做了影响最大的几条：

| 规则 | 做了什么 | 为什么要紧 |
| --- | --- | --- |
| 断词 | 一行放不下的单词在音节处断开，行尾加连字符，用的是 TeX 的美式英语规则；断点前至少留 2 个字母、后至少 3 个 | 屏幕窄，一行只放得下四五个单词；不断词的话，遇到长单词整行就会空出一大截 |
| 只拉词距 | 对齐时只加宽单词之间的空格，单词内部的字母间距永远不动 | 把字母拉散是英文排版的大忌，也是之前"一行被拉很宽"的直接原因 |
| 词距有上限 | 每个空格最多加宽四分之三个字；超过就不对齐，这一行右边留空 | 窄栏里硬要对齐，空格会大得像窟窿；偶尔一行不齐比满篇窟窿好 |
| 引号和撇号 | 词里的撇号（don’t）不断开；连字符、右引号不落在行首，左引号不留在行尾 | 和中文的行首行尾禁则是同一个道理 |
| 引号不留空洞 | 中文字体里的弯引号占一整个字宽，夹在英文里会空出一块（You’ ve）；挨着英文的弯引号按它实际的墨迹宽度占位 | 用中文字体读英文书时最显眼的毛病 |

全大写的词、带数字的词、已经带连字符的复合词不再断。中英混排的行，汉字之间和词间空格一起分担多出来的空白。

这一版没有做的：

- 其他语言的断词（英式英语、法语、德语等各有自己的规则），现在一律按美式英语断，只认 26 个英文字母组成的词。
- 整段统筹断行（TeX 的做法是一段一起算，让各行松紧尽量一致）：现在是一行一行排的。
- 连续几行都以连字符结尾时不做限制。
- 连字（fi、fl）和字偶间距。

## 还没有的

- 目录跳转。
- 图片：这个阅读器只读文字。书里的图片不显示，只有图片的章节（封面、插图页）直接跳过。
- 对时：截图文件名里的时间取自设备的时钟，真机没对过时的话日期会不对。
- 中文、英文分别设置字体（计划在以后的版本做）。
- 截图。第一版试过，在真机上截图后 TF 卡会掉线，所以先去掉了；以后恢复时再连同"同步到网盘"一起做。

## 性能与验证范围

续读时会直接准备上次的书页，省去开机图和中间等待页的刷新；仍保留物理清屏与首次完整刷新。等卡期间点屏幕不会误打开尚未显示的书库内容，中键可以取消等待、回到书库。书不在或已损坏时也会回到书库。

排版在一次操作内复用字宽；开书后的书目信息和锁屏封面复用同一个已打开文件。长章节在空闲时每次多排一页，操作后短暂推迟后台工作；后台排版失败会退出阅读并给出原有提示。

上述改动已通过主机测试、模拟器回归和固件编译，并于 2026-11-16 烧录真机验证续读、翻页、开书及锁屏唤醒。该次常规翻页的页面处理至刷新完成中位数约 312 毫秒；用户反馈顺畅、残影可接受。这是指定字体与书籍的一次试用，不代表所有书或模式。三档刷新、定期全刷与软休眠策略保持原样；续航尚未测量。

维护验证：`bash tools/run_book_host_tests.sh`、`bash tools/run_epub_host_tests.sh`、`python3 tools/run_reader_perf_tests.py`（需模拟器依赖）。阅读器串口的 `perf layout` 和 `perf page` 分别记录排版、绘制、刷屏、操作处理，以及字形缓存命中和取字耗时。`action` 从页面回调开始计算，不包含触摸控制器采样及手势识别；使用真实设备日志比较时须保持同一书、页、字体和刷新档。

### 日常使用：看完书，短按电源键就好

**两台设备都可以短按锁屏，再短按继续阅读。日常不用进入睡眠菜单，也不必每次都关机。** 锁屏会保存阅读位置，显示书籍封面或默认图片；无名还会关闭前光。

“锁屏”说的是屏幕显示什么，“休眠／关机”说的是机器在后台怎样省电。墨水屏不通电也能保留图片，所以看到封面不代表机器一直在运行，看到一张不动的图也不代表死机。

### 小纸 Pico：默认就用现在的短按方式

小纸默认使用 **深睡**。之前说明中提到的“软休眠”，在这款固件里也是指这个默认模式：主要处理器停止供电，负责检测电源键的小电路仍工作。再短按电源键，设备重新启动并恢复阅读，因此需要等几秒。

当前产品已移除旧硬件演示菜单，也不再提供其中的睡眠模式切换入口。小纸没有“长按电源键正常关机”的快捷操作，日常短按锁屏即可。以前通过演示菜单保存的睡眠模式仍保留；如果小纸显示“已关机”，长按侧面电源键约一秒再松开开机。不要照搬无名的三秒关机操作。

### 无名 Metalio：底部小键负责锁屏和关机

- **短按侧面最下面的小电源键**：锁屏；再短按继续阅读。锁屏采用浅睡，保留运行状态。
- **长按同一个键约 3 秒**：请求关机，留下电源图标和“已关机”。若显示“关机未完成”，说明机器仍在运行。
- **关机后再使用**：长按底部小电源键约 2 秒，松开后等待启动。顶部较大的键是截图键，不是电源键。

无名使用自己的电源键操作。前光可选关／低／中／高及冷／中／暖；锁屏熄灯，唤醒恢复之前的设置。

两机都在断电前画好“已关机”留屏。异常强制断电可能来不及换图；这些文字帮助区分正常操作，不能用来测量机器是否彻底断电。待机电量和长期续航尚未系统测量。


## 小纸 USB传输

书库顶部下拉，在设备信息面板点 **USB传输 → 开启**，用可传数据的 USB 线连接电脑。电脑识别后，SD 卡像普通 U 盘一样使用：EPUB 放进 `books`，TTF 放进 `fonts`。只导出 SD 卡，不导出机身设置或内置书籍。没有可正常读取的卡时不会自动格式化。

传输期间暂停阅读和自动锁屏，短按电源键不会锁屏；不要在复制中拔卡或强制关机。复制完成后，先在电脑上“弹出”整个设备，再在阅读器上点“结束”。开启后显示“已开启”和“结束”按钮；结束过程中显示“正在结束”，不可重复操作。候选版正常退出会重新读取书籍和字体，直接回到书库，不再重启；若 USB 未能完全关闭，会显示明确的重启恢复按钮。此无重启流程尚待实机复测。普通充电不会自动进入传输模式。

部分电脑没有向设备发送弹出通知，或数据线已经拔掉时，会出现退出确认。只有确认电脑已弹出，或者复制已停止且数据线已拔掉，才点击“已完成，退出”；否则取消并先完成弹出操作。设备等待已接收的读写结束，但无法补回突然断线时还留在电脑缓存里的数据。

本功能目前只在小纸编译启用；无名没有本轮 USB 入口。普通阅读不持续使用 Wi-Fi，蓝牙未启用。小纸可在主页下拉主动开启已有 Wi-Fi传书，与USB模式互斥；每日首次开机及手动校时只短时联网，结束后关闭。


## 小纸文件夹壁纸

SD卡根目录 `wallpapers/lock` 放锁屏图，`wallpapers/off` 放关机图，各自依文件名排序轮换。普通图书锁屏优先书籍封面；隐藏图书不使用书封，没有可用书封时使用壁纸。图片须先转换为684×1216的原生16灰阶 `.4bpp`，制作方法与转换工具见 [壁纸 Agent Info](WALLPAPER_AGENT.md)。

每目录最多64张，推荐 `001.4bpp` 这类编号。关机图底部会叠加“已关机”。壁纸在书库或正文停留且没有操作时分块预读；切页、USB或休眠前关闭文件。尚未准备好或读卡失败时回退默认图，不在锁屏时等待读卡。无名暂不包含这项功能。


### 小纸候选版：整句划线与短时联网

默认划线模式下，长按正文进入整句选择并选中当前句；所有可见句子显示浅色细框，选中句显示黑色粗框。点相邻句可跨段落扩选，点“划线”后才保存并留下清晰细线。选取时不翻页，但同章跨分页的一句话会完整保存；记录原文位置而非页码，卡上notes/highlights的JSONL含原文、书名、章节和UTC创建时间（未校准为空）。长按右侧全刷键切换为查词模式后，正文长按选字才显示两侧行提示点；词卡角落重选入口保留。

书库主页下拉新增日期/时分（无秒、默认UTC+8），电池在其下方；“校准时间”单击触发并显示反馈。每天首次开机用已保存网络校时，结束关闭，失败超时不阻塞阅读；失去可信RTC时需重新获取日期，不能把旧保存时间当当前时间。Wi-Fi传书只连接已有2.4GHz网络，首次在小纸配网；手机/电脑同网打开设备网址上传，停止返回后关Wi-Fi，不创建热点。目录页脚只保留“返回正文”，左右滑动翻目录页。详细操作见内置使用说明。上述为当前候选版变更，尚待实机验收。

Wi-Fi传书为阅读器原生页面，不再进入系统demo。密码页中键返回选网，选网页中键返回传书页，传书页中键或“返回书库”安全停服后固定回书库；结束过程中请等待提示。硬件演示页和书库长按中键入口已从产品中移除。

重新进入划线模式，选中已划线的句子，按钮会变为“取消划线”。只取消选中的内容，其他句子保留；同时选了未划线的句子时，按钮仍是“划线”，可补划整段。选句模式不显示两侧黑点，只有查词模式长按选字时显示。
