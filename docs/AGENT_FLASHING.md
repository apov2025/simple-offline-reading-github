# 让 Agent 协助刷机

适用于能在你的电脑上读写文件、安装工具并访问 USB 串口的编程 Agent，例如具有本机工具权限的 Codex 或 Claude Code。普通网页聊天窗口只能给建议，不能直接操作本机串口。Agent 可以按实际连接状态排查，但不能保证解决所有硬件问题，也不能代替硬件参数确认。

本次小纸使用 **2026.11.21-preview.20** 固件，编译与电脑回归已通过，尚未烧录、真机待验收。无名仍使用 **2026.11.18-preview** 原包，不能把新版小纸功能或验证状态套用到它。最新源码只做无名兼容检查；维护无名旧 BIN 应使用同日期原源码归档。

小纸普通用户下载固件包和独立词库包；词库沿用已测试的 preview.10 数据，已有同一份最新词库无需重拷。词库包内 `dict/` 整体放到 SD 卡根目录，保留来源和许可；不把大词库加入 Git 源码。

先解压与你设备匹配的固件 ZIP，把下面这段任务说明发给 Agent，并填入机型、文件夹和安装方式。完整安装会覆盖机内数据，使用者仍需接受 README 的风险说明。

## 给执行 Agent 的机器可读信息

- `manifest.json` 列出芯片、写入偏移、文件字节数和 SHA-256。只使用该固件包列出的段文件，不混用其他版本。小纸固件和新源码使用 `2026.11.21-preview.20`；无名原 BIN 对应 `2026.11.18-preview` 原源码，最新源码不是旧无名 BIN 的同版本证明。
- `SHA256SUMS.txt` 用于检测文件损坏，不构成签名认证；仍应从可信发布来源取得文件。
- 完整镜像16 MB，空白 NVS 不含用户设置。备份应读实际 Flash，不能把发布 BIN 当成用户原固件备份。
- ESP32-S3 的 bootloader 位于 `0x0`；ESP32-S31 的 bootloader 位于 `0x2000`。**两种合并 full.bin 都从 `0x0` 写入**，不要把内部组件偏移当合并文件偏移。
- 设备有安全启动／Flash 加密或其他访问限制时，先停止并查对应官方恢复流程，不变更安全配置。
- 实机序列号可用于本地锁定正确端口，但不得硬编码进公开脚本、日志或 README。
- 先确保没有其他进程或浏览器占用串口。不要结束与本次任务无关的程序。
- 如果必须让用户处理电源或线缆，说明理由，等待操作反馈；超时不等于操作已完成。

## 仍可自行网页刷机

- Metalio：[CloudZao 官方仓库／本地烧录入口](https://burner.cloudzao.com/zh/registry)，选 E-Ink4 Plus，并核对识别为 ESP32-S31。
- 小纸：[官方 DIY 固件文档](https://dot.mindreset.tech/docs/read_0/firmware) 提供构建和连接说明；导入本包 BIN 可使用 [Espressif 官方通用网页工具](https://espressif.github.io/esptool-js/)。它是芯片厂商工具，不是小纸定制系统的安装站。
- 如果设备厂商另有支持“本地 BIN”的网页，也可按该站说明使用。只安装站内预设系统、不能选择本地文件的页面，不能用来安装本包。不要把其他社区固件的“一键安装”按钮当成本包入口。

这两条路线使用同一批 BIN，区别只是由谁检查环境并执行刷写。具体偏移和数据影响见固件包 `FLASHING.md`。
