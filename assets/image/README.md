- 小纸默认图沿用上游固件资源。
- `cloudzao-lock-logo.png`：使用者提供的 Cloud Zao 标志的黑白适配，使用内置图像工具转换；保留黑色圆盘、将绿色标识/文字转白，保留原有布局，未加入其他文案。该品牌标志不代表本项目获官方背书。
- `main/assets/cloudzao_logo_4bpp.h`：320×320的4bpp编译资源（低四位像素在前），从黑白图缩放后生成。设备在684×1216逻辑画布的中心绘制，底部状态文字另行绘制。

正常编译直接使用已附头文件，不需要在线生成图片。想替换标志可自行生成同尺寸、同编码的静态数组；保留书籍封面优先的分支。软件许可证不授予第三方商标权。
